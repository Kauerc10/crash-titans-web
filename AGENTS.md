# Project instructions

PC browser reconstruction using Three.js and Rapier. Preserve verified rendering fixes and distinguish recovered source evidence from native approximations. Never commit the ISO, extracted game content, screenshots, local verification reports, credentials or dependencies. The public repository distributes code and documentation; gameplay assets are generated locally.
